** DESCRIPCION **

(FUNCIONA COMO API, REVISAR EL CONTRATO EN EL COMPONENTE DE API)
Este proyecto hace lo siguiente:

1) Verifica si la imagen corresponde a una tarjeta universitaria peruana valida
2) Extrae los datos de la tarjeta universitaria (cara frontal)
3) El proyecto corre en los dispositivos de los usuarios que utilicen la funcionalidad como API dentro de otro proyecto web usando typescript.

Tecnologias a usar

* TypeScript
* OpenCV
* Tesseract.js
