** DESCRIPCION **

Este proyecto hace lo siguiente:

1) verifique si la imagen corresponde a una tarjeta universitaria peruana valida
2) extraiga los datos de la tarjeta universitaria (cara inicial)
3) el proyecto se correra en los dispositivos de los usuarios que utilicen la funcionalidad dentro de una pagina web de registro (un proyecto aparte) 
4) el proyecto se integrara dentro de otro proyecto web con typescript

responsabilidades de las tecnologias

1) procesamiento y conexion de componentes
2) procesamiento y validacion de imagen de manera local
3) extracion de datos de imagen

Tecnologias a usar

* TypeScript
* OpenCV
* Tesseract.js
